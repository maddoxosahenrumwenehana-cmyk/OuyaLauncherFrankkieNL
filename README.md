# MadOS OUYA Launcher

An unofficial controller-focused modification of [FrankkieNL's BAXY / OUYA Launcher](https://github.com/frankkienl/OuyaLauncherFrankkieNL), prepared for OUYA-style Android consoles. This is a community project and is not an official OUYA, Android, Nintendo, or FrankkieNL release.

## Current version

`Mod-4.116.` (version code 116)

## Changes

- Updated controller-focused navigation, action prompts, and launcher-owned dialogs.
- Added battery percentage, charging/low-battery colors, and configurable date display.
- Added selectable MadOS branding and updated the launcher icon.
- Improved wallpaper scaling and removed the obsolete `gameboy-arcade` wallpaper from selection.
- Updated loading indicators and feedback contact flow.
- Added a scrollable home-screen widget area, kept the clock in a separate section, and fixed duplicate widget views on launcher resume.
- Preserved the original package and core launcher behavior where possible.

See [the release notes](GITHUB_RELEASE_DRAFT.md) for device notes and release checks.

## Build

The stable Apktool-decoded source is in `OUYAlauncher-decoded/`. From a Windows CMD prompt at this repository's root:

```cmd
apktool b "OUYAlauncher-decoded" -o "MadOS-OUYA-Launcher-unsigned.apk"
```

The output is unsigned. Sign it with your own release key before installing or publishing it. Do not commit signing keys. The generated `build/` directory is ignored and can be regenerated by Apktool.

## Device notes

- Reported device: PS202, Android 4.4.2.
- `Really Off` requires root or equivalent system privilege. On an unrooted device, Android does not allow a normal app to power off the console.
- Installing over another signature may require uninstalling the old copy, which can remove its app data.
